## ✨ Features

* 🔐 JWT Authentication
* 📦 Product & Inventory Management
* 👤 Customer Management(Coming Soon.)
* 🧾 Invoice Generation
* 💳 Payment Tracking
* 📊 Dashboard Analytics
* 📄 PDF Invoice Export
* 🔍 Advanced Search
* 🛡️ Role-Based Access
* ⚡ RESTful API

## 🏗️ Tech Stack

| Layer          | Technology |
| -------------- | ---------- |

| Database       | SUPABASE   |
| ORM            | SQLAlchemy |
| Authentication | JWT        |

## 🚀 Quick Start

```bash
git clone https://github.com/ripudamanss/BILLING_SOFTWARE_BACKEND.git

cd BILLING_SOFTWARE_BACKEND.git

pip install -r requirements.txt

uvicorn app.main:app --reload
```
